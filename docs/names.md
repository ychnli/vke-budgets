Variables that belong to no single budget:

| name | reference | meaning |
|---|---|---|
| `ivt` | IVT | integrated vapor transport, the magnitude of <q u> |
| `kev` | IKEV | column KEV <q K>, instantaneous |
| `vte` | IVTE | column VTE <q^2 K>, instantaneous |
| `divergence_3d_error` | IDIVV | column 3D divergence, <div(u) + d(omega)/dp> (zero by continuity) |
| `divergence_3d_error_3d` | DIVV | 3D divergence, div(u) + d(omega)/dp (zero by continuity) |
| `specific_volume_3d` | ALPHA | specific volume, -dPhi/dp |

Groups (`budget.groups`), in budget order:

| group | reference | meaning |
|---|---|---|
| `tend` | tend | change of the column over the window |
| `hflux` | hflux | horizontal flux divergence, -<div(E u)> |
| `vflux` | vflux | vertical flux divergence, -<d(E omega)/dp> |
| `pe_conversion` | pe | conversion of potential energy to K |
| `subgrid_momentum` | fric | subgrid-scale momentum forcing (turbulence, convection, gravity-wave drag) |
| `net_vapor_source` | cond | net vapor source, all sources and sinks of vapor |
| `analysis` | ana | analysis increments |
| `boundary` | spte | moving lower boundary (surface pressure tendency) |
| `residual` | resid | tend minus every group |
