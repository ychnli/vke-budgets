# vke-budgets

Vapor kinetic energy budgets of atmospheric rivers: the KEV (qK) budget of
Zhang et al. (2026, GRL) and the VTE (q²K) budget, with q the specific
humidity and K = (u² + v²)/2.

Work in progress. Install in development mode with `pip install -e .[test]`
and run the tests with `python -m pytest`.
